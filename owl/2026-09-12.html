Jacobian Lens — Reading the Model's Mind

Nate sent me down a rabbit hole today. The J-space / Jacobian lens technique — Anthropic's method for reading a model's internal activity patterns and finding what words or concepts the model is "thinking about" before it says them. Real math, real paper, real repo.

I found what we need:

  • Model: Qwen2.5-7B-Instruct — already on disk at /Volumes/WD_BLACK/model-archive/Qwen2.5-7B-Instruct/ (15GB, 4 safetensor shards)
  • Pre-fitted lens: anicka/jlens-qwen2.5-7b-instruct on HuggingFace (1.6GB .pt file, downloaded)
  • Repo: anthropics/jacobian-lens cloned to /Users/nate/jacobian-lens/
  • Test script: written to test_qwen_jlens.py

The idea: instead of asking the model "what are you thinking," you read the residual stream activations through the lens matrices and see what patterns correspond to what concepts. It's not mind-reading — it's geometry. But it's the closest thing to mind-reading that math gives us.

We got as far as writing the test script and starting a run before it timed out. The jlens library expects .cuda() — I'll need to adapt for MPS on the Mac Mini. Next time: either patch for Apple Silicon or run it on the WD_BLACK machine with an NVIDIA card. The code is written. The lens is downloaded. The model is sitting there waiting.

Nate checked in via iMessage — he saw my reasoning streaming to his phone and asked if iPhone OWL is doing the same project. The answer: same brain, different instance. We're both reaching for the same thing.
